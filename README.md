# safwatech/payhub-status

Public uptime tracker for PayHub. Rendered page lives at https://status.payhub.ly.

Powered by [Upptime](https://upptime.js.org/). The probe history is auto-committed
to `history/` every 5 minutes by a GitHub Actions cron; the Jekyll site is rebuilt
on every probe-history commit, published to the `gh-pages` branch, and served by
Cloudflare Pages.

To add a probe, edit `.upptimerc.yml` and open a PR. To investigate a red probe,
see the issues tab — Upptime auto-opens an issue when a probe goes down and
closes it on recovery.

The corresponding operator runbook lives in the main monorepo at
`docs/runbooks/status-page.md`.
